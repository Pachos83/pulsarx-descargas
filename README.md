# PulsarX V1 · Instalador para Windows

PulsarX es un programa de computación para diseñar redes de fibra óptica FTTH sobre postería y preparar sus
entregables: diseño automático de cajas, splitters, troncales, hilos y fusiones, planos en PDF, KMZ, reporte de
construcción, lista de material y presupuesto. Para México, Colombia, Perú y Costa Rica.

## Descarga

- **Versión más reciente:** [Releases](https://github.com/Pachos83/pulsarx-descargas/releases/latest), archivo
  `PulsarX.Instalador.exe`, o desde [pulsarx.lat](https://pulsarx.lat).
- **Manuales (PDF):** se publican en cada versión junto al instalador: uso, instalación, guía rápida y construcción
  aérea.
- **Requisitos:** Windows 10 u 11 de 64 bits.
- **Prueba gratis:** demo de 5 días (hasta 80 postes) al primer arranque.

## Comprueba tu descarga

En PowerShell, en la carpeta donde guardaste el instalador, ejecuta:

```powershell
Get-FileHash .\PulsarX.Instalador.exe
```

Compara el resultado con la huella SHA-256 publicada en [pulsarx.lat](https://pulsarx.lat) y en las notas de cada
versión. Si no coincide, no lo instales y escríbenos.
